---

Refine L3 component views in `out/workspace.dsl`.

1. Read `build/raw/manifest.json` for the list of units (containers) and
   each unit's per-unit import graph at `build/raw/imports/<unit>.json`.
2. For each container, read the source under `build/raw/source/<unit.path>/`
   and the `internal` imports list to understand the call graph.
3. Re-cluster into responsibility-named components (e.g. "HTTP Router",
   "Order Store", "Auth Adapter"). Replace the seeded filename stubs.
4. Add `componentA -> componentB "verb-phrase"` edges using the import
   graph as ground truth (skip transitive edges).
5. Keep ≤15 components per container — split or push into a sub-container
   and flag for the user.
6. Re-render Mermaid previews:
   ```bash
   structurizr-cli export -workspace out/workspace.dsl -format mermaid -output out/views
   ```
   (or via `scripts/_structurizr.py`). Ask before installing structurizr-cli.
7. Report changes per container. Do NOT publish yet.
