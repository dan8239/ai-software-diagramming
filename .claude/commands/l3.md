description: Refine L3 (Component) views in workspace.dsl
---

Refine L3 component views in `out/workspace.dsl`.

1. Read the seeded `component` declarations under each `container { ... }`.
2. For each container, read its source under `build/raw/source/<package>/` and
   the matching `build/raw/modules/<package>.modules.json` import graph.
3. Re-cluster: replace one-component-per-file with one-component-per-
   responsibility (e.g. "Session Manager", "Auth Adapter", "Retry Policy").
4. Add `componentA -> componentB "verb-phrase"` lines for the strongest import
   edges (skip transitive ones a reader can infer).
5. Keep ≤15 components per container — split into a second container if
   needed and flag for the user.
6. Re-render: `structurizr-cli export -workspace out/workspace.dsl -format mermaid -output out/views`
   (ask before installing the CLI if missing).
7. Report changes per container.
